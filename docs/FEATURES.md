# Матрица функций Элиана

Статусы:
- ✅ **implemented** — работает сервер + клиент, покрыто тестами хотя бы на уровне API.
- 🟡 **partial** — серверная часть и/или базовый сценарий есть, но интерфейс/сценарий неполный.
- 🔌 **requires_external_service** — работает только при подключении внешнего сервиса/ключа.
- ❌ **not_implemented** — нет (честно, без «нарисовано, но не работает»).

## Аккаунт и профиль

| Функция | Статус | Где |
|---|---|---|
| Регистрация с подтверждением владельцем | ✅ | `POST /auth/register` → консоль `y` → `/auth/pending/exchange-registration` |
| Вход с подтверждением | ✅ | `POST /auth/login` → `y` → `/auth/pending/exchange` |
| Сброс пароля без SMS/почты | ✅ | `/auth/reset`, `/auth/pending/exchange-reset`, `/auth/reset/complete` |
| Пароль Argon2id, политика сложности | ✅ | `lib/password.ts` |
| 2FA (TOTP) | ✅ | `/me/tfa/setup|enable|disable`, раздел «Безопасность» |
| Смена @username, имени, био, аватара | ✅ | `/me`, `/me/username`, `/me/avatar` |
| Публичная ссылка профиля `/u/<username>` | ✅ | клиентский маршрут + `GET /users/:username` |
| QR-код профиля | ❌ | только иконка; генерации нет |
| Контакты, блокировки | ✅ | `/contacts`, `/blocks` + настройки |
| Удаление аккаунта (анонимизация) | ✅ | `DELETE /me` + планировщик |
| Экспорт данных (JSON) | ✅ | `GET /me/export` |

## Мобильная навигация

Меню разделов на телефоне — кнопка-аватар в левом верхнем углу списка чатов: Настройки, Контакты, Истории, Архив, Поиск.
Прямые адреса тоже работают: `/settings`, `/contacts`, `/stories`, `/archive`.
